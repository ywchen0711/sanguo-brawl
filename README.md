# 亂世豪俠傳 · Brawlers of the Three Kingdoms

HD-2D 風格的三國動作 RPG。在東漢末年的大路上自由闖蕩，用拳腳和兵器打出連段，抓住站不穩的敵人摔出去，撿起木桶石頭砸人。向各地的高手學招式，裝上四個絕招。

An HD-2D action RPG set in the late Han. Roam the road from town to town, brawl with fists, kicks and blades, grab and throw dazed foes, hurl barrels and rocks, learn techniques from the great fighters of the age and equip four of them.

**線上玩：** https://ywchen0711.github.io/sanguo-brawl/

## 怎麼玩

| 按鍵 | 動作 |
|---|---|
| ← → ↑ ↓ / WASD | 走路（左右連按兩下：奔跑） |
| J | 攻擊，連按出連段。奔跑中按：衝撞 |
| K | 踢腿，連按出迴旋踢。奔跑中按：飛踢 |
| 空白鍵 | 跳。空中按 J / K：空中攻擊 |
| L / Shift（按住） | 防禦。防禦中按 J：上勾拳 |
| U I O P / 1 2 3 4 | 使出裝備的四個招式（要用氣） |
| E | 進門、說話、撿起東西 |
| Q | 吃藥 |
| Esc / Tab | 選單（狀態、招式、裝備、道具、地圖）。M：地圖 |

手機和平板：左下角是搖桿，右下角是攻、腳、跳、防、E 和四個招式鍵。

## 遊戲內容

- **四位英雄**：
  - 劉備：雙股劍，氣多。
  - 關羽：青龍偃月刀，攻擊距離長。
  - 張飛：最耐打，最會摔人。
  - 趙雲：最快。
  - 每個人都有自己的招式。三兄弟在桃園結義後，可以帶一位兄弟同行，由電腦操作，和你並肩作戰。
- **自由探索**：二十個地方連成一張地圖，包括涿縣、陳留、洛陽、長沙、建業五座城鎮，以及郊外、黃巾營寨、汜水關、虎牢關、江夏水寨、長江岸、南中密林和天柱山。
  - 左右走到盡頭就到下一個地方，在路標前往上（或往下）走就能岔進小路。
  - 每個地方都有推薦等級，想去哪裡都可以，但太早去會很難打。
- **打鬥**：
  - 拳、腳、兵器都能打出連段，最後一擊會把敵人打倒、打飛。
  - 被打得頭上冒星星的敵人，走過去就會抓住他。抓住後按 J 用膝蓋撞，按 K 把他扔出去砸別人。
  - 路邊的木桶、石頭、陶罐、木箱都能打破（裡面可能有錢或包子），也能撿起來扔。
  - 敵人會輪流上前、會防禦，也有弓兵和會放火的術士。
- **招式**：共二十五種，最多裝四種，在選單的「招式」裡換。
  - 一般招式：旋風腿、百裂拳、衝天拳、飛燕踢、鐵頭功、地裂震、氣功彈、回春功、金剛體、鬼神步、連環腳、迴馬槍。
  - 英雄專屬：雙股劍舞、青龍斬、燕人吼、七進七出。
  - 名將絕學：百步穿楊、雙戟風暴、虎癡衝、錦帆突、火計、五雷正法、方天亂舞、泰山壓頂、奇門遁甲。
  - **學招式的方法**：
    - 在書肆買秘笈。
    - 去道場和高手切磋，打到他認輸，他就肯教你。高手有盧植、典韋、許褚、黃忠、甘寧、太史慈和天柱山上的左慈。
    - 打倒強敵，從他的招式裡悟出絕招。
- **變強**：
  - 打倒敵人得經驗升級。
  - 在飯館吃東西會回復體力，烤鴨、松鼠魚、麻婆豆腐、紅燒排骨、人參雞湯、滿漢大餐等菜吃了能力還會永久提升。
  - 兵器鋪有兵器、鎧甲、靴子和飾品。藥舖有金創藥、大還丹和還魂丹。
- **主線**：依序打倒程遠志、張角、華雄、虎牢關的呂布，最後攻入郿塢討伐董卓。打完還能繼續闖蕩，南中的孟獲也在等你。
- **存檔**：在客棧住一晚會存檔，每到一個地方也會自動存檔。倒下了可以在最後住過的客棧醒來，帶在身上的錢會少三成。

## 畫面

人物、建築、樹木都是用程式畫的像素圖，不需要外部素材。

- 每個人物都是一副小骨架，一格一格擺出動作，填上衣服、鎧甲、頭盔、鬍子和兵器。人物約六頭身，以斜側面朝向鏡頭，看得到雙眼和兩邊肩膀。
- 每個部位會自動算出立體的明暗：受光面偏暖、背光面偏冷，金屬有反光，前面的部位會在後面投下小陰影，鎧甲有甲片紋，布料有皺褶，最後加上描邊。
- 場景是 three.js 的立體模型，加上光暈、移軸景深和調色，形成 HD-2D 的效果。
- 音效和音樂也是即時合成的。

```
js/looks.js   每個人穿什麼（英雄、高手、魔王、各種兵卒和百姓）

js/stage.js   場景：地面、街道、房屋招牌、樹、營寨、城牆、遠山、天色與燈火
js/moves.js   所有攻擊和招式的資料
js/fight.js   打鬥：動作、判定、連段、擊倒、浮空、抓摔、扔東西、飛行道具、特效
js/ai.js      敵人和同伴的打法：輪流上前、防禦、弓兵和術士保持距離
js/data.js    英雄、敵人、魔王、高手、食物、道具、裝備、地圖
js/ui.js      選單、對話、提示
js/audio.js   合成的音效與音樂
js/main.js    遊戲流程：地區、商店、道場、魔王、存檔、選單、操作、鏡頭、介面
```
